# History
Immutable record of architectural decisions and prompt history.

## adr/
Architecture Decision Records — created by sk.adr.
Format: ADR-{NNN}-{title}.md
Projects that keep ADRs elsewhere set `adr_dir` in .specify/project-config.md; sk.adr writes there instead.

## prompts/
Prompt History Records — created by sk.phr (suggested after sk.design_sub_architecture and sk.implement).
Organized by feature: prompts/{feature-name}/PHR-{NNN}-{date}.md
